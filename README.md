## Проектная работа: резиновая вёрстка "Карты подскажут"

В ходе этой базовой работе реализована страница статьи по PixelPerfect.

Главной целью работы является практика резиновой верстки с использованием смены темы.

[Макет проекта](<https://www.figma.com/design/4il8N1mlLMwSnw9wwe3tVL/%235-%D0%9A%D0%B0%D1%80%D1%82%D1%8B-%D0%BF%D0%BE%D0%B4%D1%81%D0%BA%D0%B0%D0%B6%D1%83%D1%82-(Copy)?t=J4yd6pg20bK8Yukj-0>)

#### Требования:

- Использование переменных
- Резиновость заголовков
- Декорирование абзацев
- Переключение тем
